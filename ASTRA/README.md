# ASTRA · 星空堆栈与调色

iOS 原生工程，最低 iOS 26。GitHub Actions 构建未签名 IPA；签名需要用户自己的有效证书和描述文件。Android 工程共享 C++ 堆栈内核，界面功能更新以各平台实际版本为准。

## iOS 功能

- 相册 RAW+JPEG 资产：通过 Photos 资产资源找到原始 NEF/RAW 和 JPEG，选择一种格式导入；系统会要求读取相册原件的权限。若相册不给出原件或拒绝授权，可使用「从文件导入」选择 NEF。iCloud 原件下载与逐张导入显示进度，完成一张就保存一张。NEF 导入只读元数据、提取内嵌预览用于浏览；堆栈时才使用系统 CIRAWFilter 对原件进行完整解码，不以内嵌 JPEG 冒充 RAW。导入时请保持屏幕解锁；手动锁屏后系统可能暂停相册读取。
- 星点对齐：三角星型匹配、全尺寸星点精修、曝光与背景归一化、饱和星点识别；可选主图与主体框。匹配失败的帧在照片列表显示原因。
- 分块堆栈：Float16 临时帧缓存、Float32 线性主文件；稳健剔除、星轨、水平天空与地景分离。
- HDR 多曝光融合：开启后对齐长短曝光，用未饱和短曝光像素恢复高光核心；微弱信号侧提高长曝光权重。应使用同一目标、相同焦距和构图的多档曝光。
- 自动 STF：合成结果默认在预览和成片导出中使用相同的屏幕拉伸，Float32 线性主文件不受影响。导出时可跳过 STF，或将原始线性堆栈导出为 OpenEXR。预览与全尺寸导出共享背景统计和处理顺序，星点模糊半径按分辨率缩放。星云和 STF 使用随安装包预编译的 Metal 内核。
- 智能显影：分析当前照片的线性亮度分布、天空背景及颜色偏差，为每张照片求出 STF 黑白点、背景修正、星云/星点强度和色彩参数；结果可继续手动微调。色彩和星云处理使用连续函数，不使用一键 LUT；原有固定数值模板已移除。若尚未堆栈而导入 NEF，将使用内嵌 JPEG 估算，完成堆栈后再次智能显影可基于 Float32 主文件分析。
- 星云工具：手动调整 Arcsinh 色彩保留拉伸、亮核保护、低频背景梯度消除、星云对比、云气结构、背景中和、绿色偏色抑制、星点保护、星点缩小与星点色彩。背景模型改为平滑加权估计，星云/亮核掩膜改为连续映射以减少同心色带。除 OpenEXR 线性原始导出外，调整会应用于全尺寸成片。亮核保护不是 PixInsight 的完整迭代 Masked Stretch。
- 曲线、六色 HSL、色轮、降噪与全尺寸 TIFF/PNG/JPEG/HEIF/OpenEXR 导出；JPEG/HEIF/PNG 可直接保存到手机相册，TIFF/OpenEXR 通过分享保存到文件。底部编辑工具连续横向滚动。

## 构建与验证

`bash Scripts/test_core.sh` 验证几何配准、不同曝光、饱和星点、HDR 高光恢复、真实像素合成与中途取消。`python3 Scripts/validate_package.py` 检查 Xcode 项目结构。GitHub macOS runner 进行 iOS 模拟器 UI 回归、主文件逐帧检查和 arm64 设备包归档。没有用户原始 M42 NEF 和 iPhone 真机测试，实际 RAW 支持取决于运行设备的系统解码器与照片资源权限。

使用自己的 Mac 可运行 `bash Scripts/build-unsigned.sh`。未签名 IPA 需重新签名才能安装，不能直接提交 TestFlight。工程数据位于 App 的 Documents/ASTRA，卸载 App 前请从文件 App 备份。
